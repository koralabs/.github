# .github

## Contributor test policy

Tests and coverage run locally only, never in GitHub Actions, directly or via lifecycle scripts, composites, workflow templates, or shared helpers. Organization workflow templates must preserve this policy. Keep local test commands runnable. Build, lint, publication, deployment, and production guards remain permitted. Retire obsolete required test checks from branch protections.
